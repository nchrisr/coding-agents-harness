# README tiles

The logo tiles in the main README. Regenerate them with
`python3 -I make_tiles.py <simple-icons package folder> .` after installing the `simple-icons` npm
package (version 13.21.0 was used) somewhere outside this repo.

Logos come from [Simple Icons](https://simpleicons.org) (CC0), except: the Rust logo, CC BY-SA 4.0,
by the Rust Foundation; the JavaScript logo, MIT. Azure Repos has no logo in the set, so its tile
uses initials. Every logo is a trademark of its owner, shown only to say what this harness works
with.
