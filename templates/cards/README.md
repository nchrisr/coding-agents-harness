# Starter cards

Generic cards to adapt at setup. Most projects need the first three; add others where the project
has that system. Rewrite `owns`, `watch`, invariants and "How it breaks" for the project; a card that
only repeats generic advice isn't earning its place.

| Card | Default (product) | Typical failure |
|---|---|---|
| `sign-in-and-access` | Teach me | someone does or sees what they shouldn't |
| `state-and-timing` | Keep me posted | two things at once leave a bad state |
| `money-and-numbers` | Teach me | a wrong, missing or leaked figure |
| `data-and-schema` | Teach me | lost data; code and schema disagree during a deploy |
| `privacy` | Teach me | personal data reaches the wrong place |
| `payments` | Teach me | a charge taken twice, or not at all |
| `performance` | Keep me posted | a page or job slows as data grows |
