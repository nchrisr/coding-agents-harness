# Security

If you find a security problem in the harness itself (a template, hook or script that could let an
agent or a stranger do harm, or a way around the trust rule), report it privately: on GitHub, the
repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue or
pull request for it until it's fixed.

Say what an attacker would need, what they could do, and how to reproduce it. You'll get a reply
within a week.

A problem in your own project that the harness should have caught is a finding (`CONTRIBUTING.md`),
once it's fixed in your project.
